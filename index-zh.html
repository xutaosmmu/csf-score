脑脊液系统衰竭评分（CSF评分）

针对非小细胞肺癌（NSCLC）软脑膜转移（LM）的预后评分系统。缩写"CSF"具有双重含义：Cerebrospinal System Failure（脑脊液系统衰竭）——本评分的病理生理学框架——以及 cerebrospinal fluid（脑脊液）——疾病核心所在的生物学介质。五个维度完整覆盖从肿瘤驱动性负荷到系统级衰竭的病理级联。

D1
宿主耐受性
0 – 3 分
卡氏功能状态评分（KPS）
评估时间点为LM诊断时。KPS < 60 触发双重门控机制，患者直接归入高危组，无论总分如何。
★ KPS < 60 — 双重门控激活
患者无论总分如何，直接归入高危组。该2分计入维度总分，但不需要继续填写其余维度。
LM特异性核心神经功能缺损（LM-CND）
定义为至少一项归因于软脑膜受累的主要颅神经或脊髓功能缺损——排除既往存在或由脑实质转移引起的症状。
LM诊断时颅外疾病进展状态
评估LM确诊时或确诊前的全身疾病状态，反映可用的全身治疗选择。
D2
分子引擎
0 – 2 分
具有LM特异性循证依据的CNS穿透性TKI可及性
评分反映治疗可及性，而非单纯基因变异状态。Zhang等（Front Oncol 2022）证实TKI治疗代际的预后意义超过单纯基因状态——在现代治疗时代，治疗可及性是主要预后驱动因素。
D3
解剖负荷
0 – 2 分
MRI软脑膜强化模式
依据EANO-ESMO分型（Le Rhun等，Ann Oncol 2017）。基于LM诊断时基线MRI的增强T1或FLAIR序列进行评估。
脑实质转移瘤（同期）
基于LM诊断时的基线MRI。粟粒样转移（无数微小病灶）无论确切数量，均计为≥4个。
D4
液体动力学
0 – 2 分
基线MRI Evans指数（EI）
EI = 同一轴位层面额角最大宽度 ÷ 颅骨最大内径（双顶径）。观察者间一致性κ=0.63（Le Rhun等，Neuro-Oncology 2022）。阈值≥0.27经Le Rhun等（Neurology 2024）在LM中验证具有预后意义。
CSF开放压 / 症状性脑积水
于诊断性腰椎穿刺时测量（侧卧位，充分放松）。满足以下任一条件计1分：OP > 250 mmH₂O，或临床+影像学证实的症状性脑积水需要神经外科会诊（无论记录的OP值）。
D5
生物毒性
0 – 1 分
肿瘤标志物指数（TMI）> 3
TMI = CSF肿瘤标志物浓度 ÷ 同次诊断时配对血清标志物浓度。
标志物选择层级：CEA（腺癌）→ CYFRA 21-1（鳞癌）→ NSE（神经内分泌分化）。
双重阈值设计：TMI > 3用于区分主动鞘内分泌（血-脑脊液屏障破坏被动渗漏通常产生CSF:血清比值 < 2–3）。
